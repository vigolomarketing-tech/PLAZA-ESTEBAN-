# Carpeta de assets

Archivos incluidos:

- `logo.svg` — isotipo (taza + porción de pizza) usado en el header.
- `favicon.svg` — icono de la pestaña del navegador.
- `og-image.svg` — imagen para compartir en redes (Open Graph).

## Foto del frente (recomendado)

El sitio usa una foto real del frente del local en el **hero** y en la sección
**Nosotros**. Para activarla, guardá la imagen en esta carpeta con el nombre:

```
assets/frente.jpg
```

> Mientras esa foto no exista, el sitio muestra automáticamente un degradado
> elegante como respaldo — no se rompe nada. Al agregar `frente.jpg`, la foto
> aparece sola.

**Sugerencia:** usá una imagen horizontal de buena calidad (por ejemplo
1600×1000 px) y optimizada para web (menos de ~400 KB) para que cargue rápido
desde el celular.
